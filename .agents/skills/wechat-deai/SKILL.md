# 去 AI 味

> 检测器认的是"可预测"：每个词、每个句式都是模型最可能写出的那个。模型改模型写的稿，换同义词、调语序，改完还是模型的写法，分数很难降。能把分数打下来的，是模型猜不到的东西：落到某个人身上的事，有零有整的细节，人说话时的毛病。
>
> 没有哪种改法能保证一定过检测。这类东西放得越多，分数越低。

## 何时调用

- 稿子在朱雀等平台测出 AI 率高
- 初稿写完，做"人工润色"这一步
- 作者贴回检测结果，要改标红、标黄的段落

## 流程

1. **先定设定**：不找作者要素材，动笔前自己给这篇定好

   - 叙述者"我"：多大、在哪座城市、做什么、家里几口人，比如 38 岁，在徐州管仓库，一儿一女
   - 两三个身边人，各带一个记得住的特点，比如表姐在县医院当护士，每月 5 号先转两千进余额宝
   - 每个故事配好时间、地点、带零头的数字

   整篇只用这一套设定，前后对得上。每个细节先想到的那个换掉再用，第一个冒出来的往往就是模型最常写的

2. **逐段改**：按下面的改法一段一段改，不整篇重写
3. **自查**：过一遍文末的自查清单
4. **复测**：作者在朱雀复测后贴回标红、标黄的段落，只改这几段

## 改法

### 1. 把"大家"换成具体的人

很多人、不少人、普通人、大家、年轻人、上班族，这些词都是在替一群人说话。每段至少落到一个具体的人或一件具体的事：我、我妈、楼下开小卖部的老周、前同事小杨。

### 2. 细节有零有整

- 整数换成零头：两万 → 两万三千六，几千块 → 四千八
- 写出时间、地点、牌子、平台：去年国庆、县城的万达、拼多多上 39.9 包邮
- 不罗列"咖啡机、筋膜枪、健身年卡"这种人人都写的清单，挑一样写透：哪年买的、多少钱、现在扔在哪

### 3. 打乱节奏

- 句子有长有短：有两三个字就完的（"贵。""没去。"），也有一口气说下来、中间全是逗号的长句
- 段落有长有短：有一句话的段，也有七八行的段，别每段都是三四句
- 正文不用分号、冒号、破折号，口语里没人这么断句

### 4. 删掉模型的固定套路

| 套路                         | 原稿里的例子                                                 | 怎么改                                                 |
| ---------------------------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| 段尾金句，每段总结升华       | 关起门来过日子，还是兜里有钱最实在                           | 删，让段落停在一个画面或一句原话上；全文结尾收一句就够 |
| 先前以为，后来发现           | 年轻时总觉得卡里有钱就能活得潇洒点，真攒下来才发现……         | 直接写现在发生的事                                     |
| 不是 / 不全是……而是 / 就是…… | 变抠也不全是为了省那几个钱，就是不想再花冤枉钱了             | 只留后半句，或换成一件具体的事                         |
| 三连排比                     | 吃得舒服、穿得利落，花钱算计一点                             | 留一个，写具体                                         |
| 过渡总结句                   | 除了心里发慌，还有一层很实在的变化：大家这几年算账比以前精了 | 删，直接进下一件事                                     |
| 填充词                       | 其实、说白了、说到底、归根结底、某种程度上                   | 删                                                     |
| 两头都照顾                   | 当然，也不是说出去玩不好                                     | 删，观点可以偏                                         |

### 5. 留下说话的毛病

- 语气词：吧、呗、嘛、啊、哈
- 说着说着改口：两万多，不对，快三万了
- 插一句题外话，再拐回来
- 拿不准就直说：我也说不好，反正我是这么觉得的

### 6. 结尾钩子说成自己的话

"你攒了点钱以后……评论区说说"这种问法篇篇都一样。先说自己的答案，再问：我最舍不得花的是给自己买衣服的钱，给孩子报班倒是眼都不眨。你们呢？

## 不要这么干

- 故意写错别字、同音字替换、插零宽字符、全角半角乱混：读者看着别扭，平台也会当低质内容
- 把整篇丢给另一个 AI "降重""洗稿"：换的是词，写法还是模型的
- 编极端案例，编统计数据、政策、新闻，或者把编的事安到真实的公司和名人头上：设定只用普通日子里的小事

## 示例

改后里的表姐、四千二、八千都是改稿时自己定的设定，整篇沿用。

原：

> 普通人攒点钱不容易，都是一个月一个月熬出来的。年轻时总觉得卡里有钱就能活得潇洒点，真攒下来才发现，钱就算放在那儿不花，光是知道家里遇上点事不用低头找人借，晚上睡觉都能踏实不少。

改：

> 我表姐在县医院当护士，一个月到手四千二。她存钱的办法特简单，每月 5 号工资一到，先转两千进余额宝，剩下的再说。
>
> 前年她爸住院，押金八千，她站在缴费窗口直接扫了码。
>
> "那一下，腰杆是直的。"她跟我说。

## 自查清单

- [ ] "其实""很多人""不少人""普通人""大家"全文各不超过两次
- [ ] 正文没有分号、冒号、破折号
- [ ] 没有一段是用总结句收尾的（全文结尾除外）
- [ ] 一半以上的段落里有具体的人、数字或地点
- [ ] 段落长短明显不一
- [ ] 人物设定和数字前后对得上
