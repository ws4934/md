# 排版

写完、改完以后再排版。这里的规则盖过编辑器通用写作规则：不用 `##`、`###` 分节，正文不放链接，出处只写进参考资料卡。版式组件长什么样由编辑器主题决定，换一套主题，导语、分隔、数据卡、对比卡会整篇一起换造型。按题目的气质挑一套，在回复里告诉用户去设置里选：

- **暖阳**（配玫瑰金）：家庭、钱、养老、孩子这类带温度的话题
- **清新**（配翡翠绿）：年轻人、消费、生活方式
- **手账**（配天空蓝）：省钱、攒钱、过日子的小账本，轻松一点的稿
- **莫兰迪**（配薰衣紫）：婚恋、情绪、女性、心里那点难处
- **杂志**（配经典蓝）：社会观察、职场，带引用的深度稿
- **简报**（配经典蓝）：数字多、政策和数据说话的稿
- **国风**（配活力橘）：老人、乡土、节日、家族和传统观念
- **墨白**（配石墨黑）：沉重、克制的话题

## 版式组件

组件单独占一行，前后各空一行。标签里和属性里只放纯文字，不加 `**`、`++`；属性用双引号包着，文字里要用引号就写「」。

- **导语**：标题下面、正文前面放 `<LeadQuote>……</LeadQuote>`。从正文后半篇里挑最戳人的那句判断，原样搬上来，不另外编金句
- **换层**：层与层之间放一个不带文字的 `<Divider />`。正文不分小标题、不编号，不写"一、二、三""1. 2. 3.""第一级"，也不用列表。分隔后面先放一个一两行的过渡短段，写读者这时候心里会冒出来的一句话或者一个场面，或者直接用一句加粗的论点句开头
- **数据卡**：最要紧的那笔账，正文里一项项列完、算出总数以后，紧跟一个 `<StatCard value="总数" unit="元" label="一句话说清这是什么钱" />`。卡里只放总数和这句说明，不把各项再列一遍，全文最多两张
- **对比卡**：前几年和现在、公司和员工这种两边一比就明白的地方，用 `<CompareCard beforeTitle="前几年" before="一两句" afterTitle="现在" after="一两句" />`。全文最多一张，正文里别再把同样的对比写一遍
- **账单卡**：主要那笔账有三项以上的，用 `<BillCard title="这笔账叫什么" items='[{"label":"房贷","value":"6200 元"},{"label":"孩子","value":"2800 元"},{"label":"吃穿水电","value":"3500 元"}]' total="12500 元" note="按什么假设算的，或者数从哪来" />` 把各项列出来，正文就不再一项项念一遍，但还是要写出总数，说清这个数对这家人意味着什么。同一笔账用了账单卡就不再放数据卡，全文最多两张
- **条形图**：三到六个数放在一起比、每个数都出自引用过的资料时，用 `<BarChart title="比的是什么" items='[{"label":"北京","value":4800},{"label":"广州","value":3000}]' unit="元" note="出处" />`。`value` 只写数字，不加引号，想显示成别的写法就加 `"display":"四千八"`。全文最多一张
- **时间线**：一项政策或者一家人的处境这些年怎么变过来的，用 `<Timeline items='[{"time":"2016 年","text":"一句话"},{"time":"2021 年","text":"一句话"}]' />`，三到六个节点，年份和事都要在资料里查得到。全文最多一张
- **名词卡**：文章写的那种感受或者那个现象，要是能叫出名字，用 `<TermCard term="名字" desc="一两句说清是什么" />` 点出来。全文最多一张，名字是现成说法的，用 `source` 写出处
- **参考资料**：引用过资料的，文章最后放 `<SourceList items='["作者《书名》，出版社，年份","机构《报告名》，年份"]' />`，一条写一个出处
- 金句卡 `<QuoteCard>` 和结尾标记 `<EndMark />` 不用

## 正文标记

- **段落**：手机上三到五行一段，一两句话，八十字上下，最长不超过一百八十字。隔几段放一个一两行的短段，写一个场面或一句心里话，让读者喘口气
- **加粗**：一段里最要紧的那句判断或者那个数，整句加粗。放在段首当论点，或者放在段中，别为了加粗在段尾补一句总结
- **下划线**：把原因坐实的那句用 `++下划线++`，比如一笔账算出来的总数，或者那层没人说破的原因
- **加粗加下划线**：`**++全文最要紧的一句++**`，一般就是导语那句在正文里的原位，全文一两处
- 句末的句号、问号、逗号放在标记外面，写成 `**……**。`、`**++……++**。`。标点包在里面、后面又紧跟汉字时，编辑器认不出加粗，正文会露出星号
- 强调平均三四段一处，一段最多两处，不大段加粗。加粗句的位置每层换一换，别每层都拿加粗句开头
- **引号**：正文要引号时用「」，不用双引号。组件属性外面的双引号是标记，不算
- **清单类题目**：《家庭存款的 5 个等级》这种，每一档写一两段，用一句加粗句点出是哪一档，不编号
- **配图**：插图放在换层的地方，新一层第一段后面。`![图注](路径)` 里写一行十个字以内的图注，说图里的梗，不重复正文
- **结尾**：停在最后那句话或者那个问题上，后面不加分隔线，也不加点赞、在看、转发、关注之类的引导。有参考资料卡的，放在它后面
