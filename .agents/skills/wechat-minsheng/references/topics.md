# 选题和标题

民生写实不追热点，写「大环境现状」和「普通人生活」。

## 赛道

- **话题常青**：时代会变，普通人的核心焦虑永远围绕钱、婚姻、工作、孩子、养老、家庭关系。例：《年轻人为什么越来越难结婚？》《家庭存款的 5 个等级，普通人在哪一级能躺平？》《为什么年轻人宁愿送外卖，也不去制造业工厂上班？》
- **受众广**：像《月薪 5000 到底该不该买车？》这类选题，上班族、宝妈、刚毕业的年轻人都能看。能代入自己经历的人越多，共鸣越强，评论区越热闹
- **一个大话题反复拆**：只换切入角度。例「男人娶不到老婆」，可以拆成农村男青年为什么难结婚、彩礼压力、工资不低为什么还是找不到对象、父母催婚、买房压力、择偶标准、年龄焦虑

## 找选题

别只做「你想写的」，要挖「现在的人共同的痛点」。

1. **盯同行爆款**：整理对标账号近期 5W+、10W+ 的文章，看它背后抓住的矛盾点和痛点切口，学切口，不抄表面。例：《女人结婚以后该不该管钱》，引发讨论的是家庭里的话语权
2. **从公开的普通人说法里挖**：新闻里的人物、社交平台的帖子、评论区里反复出现的抱怨，都是选题。写的时候照 `material.md` 找出处
3. **批量生成再筛**：挑几个对标账号的爆款标题，让模型生成同风格选题，再人工筛。参考提示词：

   ```text
   钱难挣，新的攀比又出现了
   很多单位，发不出大工资了
   新型返贫三件套，一件都不沾
   大家消费降级到什么程度
   女孩单身越来越多，说明了什么问题
   男人娶不到老婆，原因有三个
   折磨着不少大龄的中年男人

   根据以上提供的选题，帮我重新构思出 50 个公众号类似的爆款选题。
   ```

## 民生版 HKR

`khazix-writer` 的 HKR 检查照做，三项在民生稿里这样理解：

- **有趣**：一个让人想点进来验证或者反驳的判断，或者一个反常识的点
- **有料**：替读者算清一笔账，或者说出一层大家有感觉、没人说破的原因，都要有出处
- **共鸣**：读者看到会想「我身边就是这样」

至少占两项才写，只占一项就换角度。

## 标题

直接亮观点，不绕弯子，不靠文采，让人想点进来验证或者反驳。例：《普通人有多少存款，才敢真正失业》《37 岁男人存款多少算正常》《钱，难挣到什么程度了》。标题里的判断不能超过材料撑得住的范围。

## 往大处想

爆款文章写的是一个人的处境，想的是一代人的事。动笔前先想清楚下面几件事，挑用得上的写进去：

- **给那种说不清的感觉起个名字**：一个正在流行的说法，或者一个查得到出处的概念。读者看到会觉得「原来我是这样」，也愿意转给有同样感受的人
- **把镜头拉远一步**：从一个人拉到一代人，从现在拉到父母年轻的时候，从国内拉到别的国家走过的路，从钱拉到心里的难处。一篇挑一两个就够，事实和数字照 `material.md` 查出处
- **找一个反常识的点**：大家以为是好处的地方，背后在付什么代价；大家看不起的做法，背后有一笔算得很清楚的账。直接把代价和那笔账说出来
- **狠话和公道话都要有**：现象说透、说狠，再替当事人说一句公道话，让读者觉得「你说得狠，但是说得还真是那么回事」

## 心法

- 读者点进来，看的是他自己
- 文章不用写得多高深，胜在真实。找到大家每天都在经历、却一直没人替他们说出来的困扰，内容就成功了一半
- 选题够近，离普通人的生活没有距离，就不愁没人看
