# 公众号「民生写实」写作 Skill

> 赛道定位：不追热点，专注「大环境现状」与「普通人生活」。标题短小吸睛，内容不求高深但极具共鸣。

## 何时调用

- 找民生写实类选题，或把一个大话题拆成多篇
- 按 6 步框架写公众号文章
- 给文章配封面图和插图

## 赛道要点

- **话题常青**：时代会变，普通人的核心焦虑永远围绕 **钱、婚姻、工作、孩子、养老、家庭关系**。例：《年轻人为什么越来越难结婚？》《家庭存款的 5 个等级，普通人在哪一级能躺平？》《为什么年轻人宁愿送外卖，也不去制造业工厂上班？》
- **受众广**：像《月薪 5000 到底该不该买车？》这类选题，上班族、宝妈、刚毕业的年轻人都能看。能代入自己经历的人越多，共鸣越强，评论区越热闹。
- **一个大话题反复拆解**：只换切入角度。例「男人娶不到老婆」→ 农村男青年为什么难结婚？/ 彩礼压力 / 为什么工资不低还是找不到对象？/ 父母催婚、买房压力、择偶标准、年龄焦虑等。

## 找选题

原则：别只做「你想写的」，要挖出「现在人共同的痛点」。

1. **盯同行爆款**：整理对标账号近期 5W+、10W+ 的文章，分析背后抓住的**矛盾点**和**痛点切入口**，学切口不抄表面。例：《女人结婚以后该不该管钱》，引发讨论的不是"管钱"，而是"家庭里的话语权"。
2. **从自己身边挖**：同事辞职去送外卖、朋友结婚几年还在还债、父母总觉得存款放银行才踏实……自己经历过、听过、见过的事天然带有细节，有细节才有「活人感」。
3. **用 AI 生成**：挑几个对标账号的爆款标题，批量生成同风格选题，再人工筛选优化。参考提示词：

   ```text
   钱难挣，新的攀比又出现了
   很多单位，发不出大工资了
   新型返贫三件套，一件都不沾
   大家消费降级到什么程度
   女孩单身越来越多，说明了什么问题
   男人娶不到老婆，原因有三个
   折磨着不少大龄的中年男人

   根据以上提供的选题，帮我重新构思出 50 个公众号类似的爆款选题。
   ```

## 6 步写作框架

1. **标题直接亮观点**：不绕弯子，不靠文采，让用户想点进来验证或反驳。例：《普通人有多少存款，才敢真正失业》《越来越多年轻人不买车，不是因为穷》《37 岁男人存款多少算正常》《钱，难挣到什么程度了》
2. **开头两三句话扔「扎心结论」**：不要上来就铺垫宏大背景，让读者第一眼觉得"这件事真的就发生在我身边"。
3. **用一个具体故事立住情绪**：不要干巴巴地分析收入结构或讲大道理，直接上具象人物与场景。全文只在这里写一个人，三五句话、两百字以内写完；写一类人的典型处境，不编"我朋友""我亲戚"的亲历。例：一个 30 多岁的上班族，卡里有 20 万，看着不少；但孩子要上学、父母身体不好、每个月还有房贷，连辞职空窗两个月都不敢。
4. **把核心观点拆成 2~3 层，一层比一层深**：每一层只说一件事，别一大坨文字堆到底。下一层接着上一层的话头，往下问一句"为什么"或者"那又怎么样"，别写成并列的几条理由。例：想辞不敢辞 → 怕的是空窗那几个月账单照扣 → 空窗这么吓人，是因为出去以后不一定接得上 → 接不上也不敢赌，是因为工资后面跟着一家人。每一层都留一点情绪，让读者边看边想"确实，我身边就是这样"。层里不再加人物故事。字数跟着内容走：每一层把下面三样写完就收，不凑字也不硬砍。题目窄、两层就说透的，全文一千五六百字也行；清单类标题（比如《家庭存款的 5 个等级》）每一档写一两段，用一句加粗句点出是哪一档，全文可以到三千多字。写完不到一千五百字，多半是哪一层缺了原因或证据，补上，别加车轱辘话。每一层都要有三样：
   - 一个大家都见过的场面，让人点头
   - 背后的原因，那一层大家心里有感觉、但是没人说破，用大白话讲透。例：前几年大家敢花钱，靠的是心里有底，觉得下个月、明年还能挣回来（只是示范，别照搬这句）
   - 一个把原因坐实的证据：一笔账、前几年和现在的对比、一个更具体的场面，或者一条查得到出处的研究、书、统计数据。全文最多两笔账，算的是"比如说"的一户人家，一项项列出来、算出总数，每笔只算一遍；行业工资、找工作要几个月这类数据，没查到出处就别写具体数

   三样怎么排每层换一换，别每层都是同一个套路，也别每层都用"我们来算一笔账"开头

   **引用**：有联网搜索就去搜，找查得到出处的研究、书、官方统计或者正规媒体的报道，用来坐实某一层的原因，全文一两处就够。人名、书名、机构、年份和数字都照搜到的原文写，人名第一次出现带上身份，写清楚是哪国、哪个机构、做什么的。用大白话转述，说完马上落回普通人的日子，别堆理论。没有搜索工具或者搜不到，就不引，不凭记忆写人名、书名和数字。

   **最后可以落到普通人能做什么**：给一两个具体、做得到的办法，别用"首先、其次、最后"排，别写成鸡汤，也别装作有标准答案。
5. **避坑与误区**：
   - 不要为了制造冲突而故意编造极端案例
   - 不要篇篇都写成「男女对立」
   - 可以让评论区热闹，但内容不能恶意制造矛盾冲突。要让用户觉得"你说得狠，说得还真是那么回事"
   - 抄需求，不抄答案：别看到同行标题爆了就换几个词反复发同一个选题，长期会导致账号模板化、被「低质限流」
6. **结尾**：两三句话收尾，不把前面几点再讲一遍。可以留一个低门槛、有代入感的问题，也可以停在一句实在话上；要问就只问一个。例："你身边有没有这样的人？""你觉得一个家庭存多少钱，才算真正有安全感？"

### 往大处想

爆款文章写的是一个人的处境，想的是一代人的事。动笔前先想清楚下面几件事，挑用得上的写进去：

- **给那种说不清的感觉起个名字**：一个正在流行的说法，或者一个查得到出处的概念。读者看到会觉得"原来我是这样"，也愿意转给有同样感受的人。开头也可以从这个说法切进去，先摆一两个大家见过的例子，再亮判断
- **把镜头拉远一步**：从一个人拉到一代人，从现在拉到父母年轻的时候，从国内拉到别的国家走过的路，从钱拉到心里的难处。一篇挑一两个就够，事实和数字照"引用"的规矩查出处
- **找一个反常识的点**：大家以为是好处的地方，背后在付什么代价；大家看不起的做法，背后有一笔算得很清楚的账。直接把代价和那笔账说出来，别用"不是……而是……"翻转
- **狠话和公道话都要有**：现象说透、说狠，再替当事人说一句公道话，让读者觉得"你说得狠，但是说得还真是那么回事"

## 去 AI 味

写完逐条检查，改掉再交稿：

- 不用"不是……而是……""不是 A，是 B"这类先否定再翻转的句式，直接说后半句
- 段落不用金句、总结句收尾，也不加粗口号，停在一个场面或一笔账上；全文只在结尾收一次。这条只管收尾，原因照样要在段落中间讲透
- 不写过渡总结句（"除了……还有一层……""无非是卡在三个地方"），直接进下一件事
- 不写"以前总觉得……后来才发现……"，直接写现在的事
- 不凑三连排比，留一个写具体
- 删填充词：其实、说白了、说到底、归根结底、无非、某种程度上
- 正文不用破折号和分号
- 句子和段落有长有短，别每段都是三四句

### 交稿前再改一遍

最后把书面稿改成口述稿。只改说法，意思、数字和时间单位一个不动，"的""地"照规范用：

1. 关联词写全：转折一律用"但是"，因果写成"因为……所以……"，再补上"虽然……但是……""如果……的话""比如说"
2. 补上口语虚字：的时候、里面、上面、以后、一些、比较、去
3. 主语写出来，不省略
4. 比喻和精心设计的说法换成大白话或常见成语；简称写全，如"私企"写成"私营企业"
5. 不用冒号，改成逗号或"那就是"；直接引语改成转述
6. 数字一部分改成阿拉伯数字加"元""块钱"，一部分保留中文
7. 用逗号把几件事串成一句，句子拉长

## 排版

改完口述稿以后再排版。颜色、行距、线条交给编辑器主题。编辑器内置了几套主题，按题目的气质挑一套，在回复里告诉用户去设置里选：

- **暖阳**（配玫瑰金）：家庭、钱、养老、孩子这类带温度的话题
- **清新**（配翡翠绿）：年轻人、消费、生活方式
- **杂志**（配经典蓝）：社会观察、职场，带引用的深度稿
- **墨白**（配石墨黑）：沉重、克制的话题

标记只用下面这几种：

- **不分小标题、不编号**：正文从头到尾是连着的段落，不用 `##` 小标题，不写"一、二、三""1. 2. 3.""第一级"，也不用列表。换层靠一个一两行的过渡短段，写读者这时候心里会冒出来的一句话或者一个场面，或者用一句加粗的论点句开头
- **导语**：标题下面、正文前面放一句 `> 引用`。从正文后半篇里挑最戳人的那句判断，原样搬上来，不另外编金句
- **段落**：手机上三到五行一段，一两句话，八十字上下，最长不超过一百八十字。隔几段放一个一两行的短段，写一个场面或一句心里话，让读者喘口气
- **加粗**：一段里最要紧的那句判断或者那个数，整句加粗。放在段首当论点，或者放在段中，别为了加粗在段尾补一句总结
- **下划线**：把原因坐实的那句用 `++下划线++`，比如一笔账算出来的总数，或者那层没人说破的原因
- **加粗加下划线**：`**++全文最要紧的一句++**`，一般就是导语那句在正文里的原位，全文一两处
- 句末的句号、问号、逗号放在标记外面，写成 `**……**。`、`**++……++**。`。标点包在里面、后面又紧跟汉字时，编辑器认不出加粗，正文会露出星号
- 强调平均两三段一处，一段最多两处。加粗句的位置每层换一换，别每层都拿加粗句开头
- **配图**：插图放在换层的地方，新一层第一段后面。`![图注](路径)` 里写一行十个字以内的图注，说图里的梗，不重复正文
- **结尾**：停在最后那句话或者那个问题上，后面不加分隔线，也不加点赞、在看、转发、关注之类的引导。引用过资料的，最后空一行，用斜体列出来：`*参考资料：作者《书名》，出版社；机构《报告名》，年份*`

## 配图风格

一篇文章的封面和插图要像同一个人画的：同一个 IP 主角、同一套画风、同一个背景色。

### IP 形象

账号所有配图都由同一个 IP 出演，用表情和动作把标题里的处境演出来。读者记住了这个形象，也就记住了账号。

**先看用户选过没有**：桌面端会把用户的 IP 库放在工作区的 `ip/library.json`，用户在设置 →「IP 形象」里管理它：

```json
{
  "defaultId": "…",
  "characters": [
    {
      "id": "…",
      "name": "…",
      "description": "…",
      "prompt": "…",
      "image": "ip/….png"
    }
  ]
}
```

- 有 `defaultId`：直接用这个 IP，它的 `prompt` 就是模板里的 `Character` 一行；回复里告诉用户本篇用的是哪个 IP
- 库里有 IP 但没有默认：列出名字和描述让用户挑一个，或者出新的候选
- 库是空的、没有 `ip/` 目录，或者用户要换新形象：出候选让用户选

**出候选让用户选**：

1. 设计 3 个候选，物种或造型拉开差距（比如一只动物、一个人、一个拟人的物件），都符合下面的画风
2. 每个候选写三样：名字、一句中文描述、英文 `Character` 描述。描述要细到每次都能画成同一个样子：体型和几头身、毛色或肤色、一个记得住的特征、一件固定的衣服；不写表情，表情留给每张图的 `Scene`
3. 每个候选出一张示例图：`Scene` 写 `standing and facing the viewer, relaxed neutral pose`，米色背景，1:1
4. 把名字、描述和示例图发给用户，**停下来等用户选**，选定之前不画文章配图
5. 用户选定后，在工作区写 `ip/selected.json`，app 会把它存进 IP 库并设为默认，以后的新文章直接沿用：

   ```json
   {
     "name": "阿土",
     "description": "穿砖红卫衣、左眼一圈棕斑的中华田园犬",
     "prompt": "a chubby anthropomorphic Chinese rural dog ...",
     "image": "images/ip-candidate-1.png"
   }
   ```

   用户要换回库里已有的 IP，写 `{ "id": "<库里的 id>" }`。没有 `ip/` 目录时不写文件，这次对话里一直沿用选定的 `Character` 描述

一个合格的 IP 描述，以阿土为例：

- **中文**：直立行走的中华田园犬，胖乎乎的梨形身材，约 2.5 头身；奶白色的毛，左眼一圈圆形棕斑；三角耳，耳尖往下折；黑豆眼；卷尾巴；永远穿同一件洗旧的砖红色卫衣
- **Character**：`a chubby anthropomorphic Chinese rural dog standing upright on short legs, about 2.5 heads tall, pear-shaped body, cream-white fur with a round brown patch around the left eye, short triangular ears with folded tips, small black dot eyes, tiny mouth, short curled tail, wearing a faded brick-red hoodie.`

IP 怎么演：

- **情绪**：表情跟着这张图的那段话走，心疼、算计、嘴硬、偷乐、认命都行，同一篇里别重样；带点自嘲和幽默，不苦大仇深
- **配角**：家人、同事、老板需要出场时，用同样画风的简化造型，比 IP 小、颜色淡，不抢戏

### 画风

- **线条**：手绘卡通，深色描边粗且略带抖动，色块平涂，带一点蜡笔或颗粒纸的质感；造型圆钝简化，像绘本或报刊漫画
- **配色**：颜色少而饱和，芥末黄、橘色、草绿、砖红为主
- **背景**：一整块纯色。一篇文章只定一个背景色（芥末黄、米色、浅草绿任选其一），封面和插图共用
- **构图**：IP 始终是主角。封面居中；插图按梗换景别，特写、全身、俯视都行，同一篇别每张都一样
- **不放字**：标题在图下方，画面里不出现文字和数字

### 标题怎么变成画面

先找这段话里最戳人的那个细节，再给它一个梗，让人看了会心一笑。标题里的比喻别照字面画，拧水龙头、撑伞、抱存钱罐这些第一反应都换掉。找梗有三个办法：

- **夸张**：把一件小事画大
- **反差**：表情和处境反着来
- **用上 IP 自己**：身体、特征、衣服都能拿来演戏

文中插图同理，每一层讲的事换一个梗，IP 和背景色不变。以阿土为例：

| 标题                                 | 画面                                                         | 梗          |
| ------------------------------------ | ------------------------------------------------------------ | ----------- |
| 《亏掉 20 万太容易了》               | 阿土咧嘴笑着冲镜头竖大拇指，身后的钞票长着小翅膀排队飞出窗外 | 反差        |
| 《家庭存款的十个等级，你到哪一级了》 | 阿土站在一架高梯子的最底下一格，仰着脖子看，梯子顶端扎进云里 | 夸张        |
| 《钱，难挣到什么程度了》             | 阿土满头大汗拉着一辆比它大十倍的板车，车上只放着一枚硬币     | 夸张        |
| 《新型返贫三件套，一件都不沾》       | 阿土挤在一辆塞满家当的小汽车里，耳朵被车顶压弯了             | 用上 IP 自己 |

规格：封面横版 2.35:1（如 900×383），IP 放中间，转发时裁成 1:1 缩略图也能看清；文中插图统一 4:3。

### 一篇文章的图怎么保持一致

1. 每张图都用下面的模板：`Character`、`Style` 两行原样照抄，一个词都不改；`Background` 整篇用同一个颜色；只改 `Scene` 和 `Composition`
2. 出图时带上参考图：用 `generate_image` 就把 IP 的 `image`（如 `ip/<id>.png`）放进 `reference_images`；封面定稿后，插图再加上封面。其他生图工具支持参考图的，也这样传
3. 一篇文章的图用同一个工具、同一个模型一次出完，中途不换

### 提示词模板

```text
Character: {the IP's prompt, verbatim}
Style: flat hand-drawn cartoon illustration, thick slightly wobbly dark outlines, flat color fills with subtle crayon and grainy paper texture, simple rounded shapes, picture-book editorial cartoon, humorous and relatable mood, a few saturated colors such as mustard yellow, orange, grass green and brick red.
```

## 核心心法

- 你以为你是在写别人，其实用户点进来，看的是**他自己**。
- 文章不用写得多高深，**胜在真实**。找到大家每天都在经历、却一直没人替他们说出来的困扰，内容就成功了一半。
- 选题够近：离普通人的生活没有距离，内容需求就不会差。
